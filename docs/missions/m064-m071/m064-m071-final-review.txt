MINORS:
- The `acceptance.py` trust-boundary scan (`_git_offenders`, `_process_offenders`) only globs `*.py` one level deep in the realworld package directory. If a subdirectory were ever added under `src/trajectory_os/realworld/`, those files would escape the scan. Currently the package is flat so this is not a live issue, but a `rglob("*.py")` would be more future-proof.
- In `scripts/m064_m071_bundle_evidence.py`, the `build()` function calls `shutil.rmtree(runtime)` unconditionally at the top. If a user pointed `--runtime` at a directory containing unrelated data, it would be destroyed. The default (`.artifacts/m064-m071/bundle`) is safe, but a guard (e.g., verify the path is under the repo or is a known artifact prefix) would reduce foot-gun risk.
- The `lifesci.py` entity-detection regex (`_ENTITY_RE`) matches only capitalized multi-word names followed by a known corporate suffix. Single-word company names (e.g., "Moderna", "Pfizer") without a suffix will not be detected. This is a known limitation of the deterministic approach and is acceptable for a first pass, but worth noting in the ADR's "Limitations" section for future readers.
