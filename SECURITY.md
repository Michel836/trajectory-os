# Security Policy

TrajectoryOS is currently an experimental project.

## Security principles

- Local-first processing where practical.
- Never commit secrets or credentials.
- Never include personal or client data in the public repository.
- External AI providers must be accessed through explicit adapters.
- Human approval is required for irreversible or high-impact actions.
- Agent permissions must follow least-privilege principles.
- Tool calls and consequential actions should be auditable.
- Inputs from external sources must be treated as untrusted.

## Public data

Only synthetic, anonymized or explicitly approved demonstration data may be
included in the public repository.

## Vulnerability reporting

Do not disclose sensitive information in public GitHub issues.
